# Active-probe simulator pilot v1

This archive records a three-seed simulator-backed diagnostic pilot after adding the optional active-probe channel.

- Seeds: `0`, `1`, and `2`.
- Training: two generations per condition.
- Evaluation: eight steps per condition.
- Conditions: direct, indirect, spatially decorrelated, no-field, and reversal intervention.

## Observed diagnostic pattern

- Probe rate was approximately `0.50` in every condition.
- No-field probe signal and probe-outcome information were zero.
- Indirect probe-outcome information was higher than direct in this pilot.
- Survival was `1.0` and reproduction was `0` in every condition.

The approximately one-half probe rate is consistent with an uncalibrated gate, not selective information seeking.
The pilot therefore provides a useful negative result: the probe channel and no-field control work, but the current training horizon does not produce evidence of learned active probing.

This is engineering evidence only.
It does not establish environmental awareness or consciousness.
