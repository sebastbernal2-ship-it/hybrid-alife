# PPO-POET final held-out campaign

This archive contains the completed two-replication `poet` versus `static` campaign.

## Design

- Tracks: `poet` and `static`.
- Seeds: `0` through `9` per replication.
- Generations: `200` per cell.
- Held-out environments: `4` per cell.
- Transfer score: undiscounted raw reward from deterministic frozen-policy rollouts.
- Artifact schema: `2`.
- Declared launch commit: `fa965bd`.

Held-out environments use a separate seed stream and are excluded from training, selection, mutation, and archive admission.

## Preregistered result

The analyzer completed all 40 cells and returned `insufficient_evidence`.
The preregistered success gate did not pass.

| Replication | Mean poet - static | Exact paired p | Bootstrap 95% CI |
|---|---:|---:|---:|
| `replication-1` | -0.1640 | 0.6250 | [-0.6978, 0.3729] |
| `replication-2` | -0.8563 | 0.03125 | [-1.3755, -0.3346] |
| pooled | -0.5101 | not used for gate | [-0.9131, -0.1089] |

The dynamic POET track had higher final in-distribution transfer than static training.
Its mean final transfer was `9.0049` versus `2.6448` for static.
That improvement did not transfer to the held-out environments under this protocol.
This archive does not support a claim that POET improves held-out transfer.

## Provenance audit

`audit_report.json` records the independent artifact checks.
All 40 cells use schema version `2`.
All held-out matrices are finite, frozen-policy, excluded-from-training, and shaped `2 x 4`.
The policy parameters differ in every paired cell.
Seven of twenty paired held-out matrices are exactly equal despite different final policies.
This is a diagnostic flag for policy-behavior or task-sensitivity analysis, not a basis for changing the preregistered result.

Artifact `source_commit` values vary because documentation-only commits occurred while the run was active.
The audit found no changes under `src/`, `scripts/`, `tests/`, or `configs/poet_campaign.yaml` between the declared launch commit and those artifact commits.
